# SOP-007 Protocol Amendments

SYNTHETIC policy document for the TrialScout teaching demo.

## Purpose

Governs how protocol amendments are classified, approved and implemented.

## Substantial Amendments

Rule PA-1: substantial amendments (changes to endpoints, sample size >10%, eligibility or safety monitoring) require IRB/EC approval before implementation and notification of the DSMB if one exists.

## Phase 3 Oversight

Rule PA-2: every Phase 3 protocol must name an independent Data Safety Monitoring Board (DSMB).
