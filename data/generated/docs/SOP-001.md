# SOP-001 Informed Consent

SYNTHETIC policy document for the TrialScout teaching demo.

## Purpose

Defines how informed consent is obtained, documented and refreshed for all interventional studies.

## Consent Version Control

Only the IRB/EC-approved consent version listed in the protocol may be used. Rule IC-1: the protocol must reference an approved consent form version of 2.0 or higher for any amended protocol.

## Re-consent

Rule IC-2: when an amendment changes risks, procedures or visit burden, active participants must be re-consented within 30 days of IRB approval of the amendment.
